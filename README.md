## 1. 프로젝트 개요
![Image](https://github.com/user-attachments/assets/5a12ede1-8458-4163-9e87-15d757899b4c)
 
Ticket Open Wave, <br>
다양한 플랫폼에서 판매하는 티켓들을 한 곳에 모아 쉽고 간단한 검색만으로 원하는 티켓 오픈 정보를 쉽게 찾아낼 수 있게 도움을 주는 티켓 오픈 플랫폼입니다.<br> 
다양한 오픈티켓정보를 한눈에 알아보고 원하는 티켓정보를 수월하게 얻을 수 있습니다.


## 2. 개발 배경 및 개발 목표
현대인의 여가생활에서 공연, 콘서트, 뮤지컬, 스포츠 이벤트 등 다양한 티켓 구매의 수요가 꾸준히 증가하고 있습니다. 그러나 현재 국내 티켓 예매 시장은 '인터파크 티켓', '멜론 티켓', 'YES24 티켓', '티켓링크'와 같은 주요 플랫폼이 각각 자사의 독점 판매 티켓을 중점적으로 운영하며 이끌어가고 있습니다.<br> 
이에 따라 사용자는 원하는 티켓 정보를 얻기 위해 여러 사이트를 번거롭게 검색해야 하는 불편함을 겪게 됩니다. <br>
특히, SNS나 블로그를 통해 이벤트 정보를 접한 사용자는 각 티켓 예매 사이트를 직접 찾아다니며 정보를 확인해야 하는 경우가 많아 비효율적인 경험을 겪고 있습니다. <br>
이러한 문제를 해결하기 위해 팀 TOW는 국내 주요 티켓 사이트들의 티켓 오픈 정보를 통합적으로 제공하는 Ticket Open Wave 프로젝트를 기획했습니다. <br>
 Ticket Open Wave는 다양한 티켓 정보를 통합적으로 제공하고, 개인화된 경험을 통해 사용자 만족도를 높이는 플랫폼 개발을 목표로 삼았습니다. <br>

## 4. 차별화 전략
•	통합 정보 제공: 여러 티켓 예매 플랫폼의 정보를 매일 크롤링하여 사용자에게 한눈에 비교 가능한 형태로 제공. <br>
•	지역 기반 필터링: 사용자가 선택한 지역의 티켓 정보를 제공하여, 사용자의 활동범위 내에서 공연하는 티켓 정보 제공. <br>
•	네이버 지도 및 길찾기 연동: 티켓 구매 후 쉽게 방문할 수 있도록 지도 및 길찾기 사이트 연동 기능 제공. <br>
•	소셜 로그인 지원: 간편한 회원가입과 로그인을 위해 주요 소셜 네트워크 계정 연동 지원. <br>

# 5. 시스템 구성도
## 5.1 시스템 구성도
### 개요
Towave는 사용자 친화적인 인터페이스를 제공하여 티켓 정보를 관리하고 관심 목록을 설정할 수 있는 웹 애플리케이션입니다. 이 애플리케이션은 AWS EC2에서 호스팅되며, NGINX와 Spring Boot를 사용하여 클라이언트와 서버 간의 원활한 통신을 지원합니다.

### 아키텍처

### 1. 사용자 접속
- 사용자가 웹 브라우저를 통해 도메인 `towave.site`에 접속합니다.
- 요청은 AWS EC2에 있는 웹 서버로 전달됩니다.

### 2. 웹 서버 (AWS EC2)
#### NGINX 활용
1. **클라이언트 (포트: 80)**
   - 클라이언트의 요청을 수신하고, 필요한 정적 자원(HTML, CSS, JavaScript)을 반환합니다.
   - 클라이언트에서 API 요청이 있을 경우, 이를 백엔드로 전달합니다.

2. **백엔드 (포트: 8080, 프록시 경로: /api)**
   - 클라이언트의 API 요청을 처리합니다. (Spring Boot 기반)
   - 요청 예시:
     - **로그인 요청**: 사용자 인증을 위한 정보 처리.
     - **관심 목록 조회 요청**: 사용자가 저장한 관심 티켓 정보를 반환.
     - **관심 목록 알람 설정 요청**: 알람 설정을 위한 데이터 저장.
   - 데이터베이스(MySQL)와 상호작용하여 필요한 티켓 정보를 조회하거나 업데이트합니다.

### 3. 데이터베이스 (MySQL)
- 티켓 정보, 사용자 정보, 관심 목록, 알람 설정 등을 저장합니다.
- 백엔드 서버로부터의 요청에 따라 데이터를 조회하거나 관심, 알람 목록을 업데이트합니다.

### 4. 크롤러
- 멜론, 인터파크, YES24 등 외부 사이트에서 티켓 정보를 주기적으로 크롤링합니다.
- 수집된 데이터는 MySQL 데이터베이스에 저장됩니다.

### 설치 및 실행
1. 필요한 패키지를 설치합니다.
2. AWS EC2에 웹 서버를 설정합니다.
3. NGINX와 Spring Boot를 구성합니다.
4. MySQL 데이터베이스를 설정합니다.

### 6.2.2 결과 분석
#### 1. 검색 필터
- **설문 결과**: 가장 유용한 필터를 묻는 설문에서 공연 지역, 공연 날짜, 공연 장르 필터가 각각 비슷한 비율로 선택되었습니다. 따라서 세 가지 필터 모두 필요하다는 결론을 도출할 수 있습니다.
- **날짜 필터 수정**: 사용자 의견에 따라 ‘기간보다는 그냥 날짜 하루로 검색할 것 같다’는 의견을 반영하여, 최종 버전에서는 날짜 필터 컴포넌트의 기능을 수정하였습니다.

#### 2. 상세 페이지
- **성별 통계 삭제**: 티켓을 선호하는 성별 통계가 필요 없다는 의견이 지배적이므로, 해당 기능을 삭제하였습니다.
- **잔여 티켓 유무**: 잔여 티켓 유무에 대한 요청이 있었으나, 시시각각 변하는 티켓 정보를 완벽하게 제공할 수 없기에 제외하였습니다.
- **공연 추천 기능**: AI를 활용하기보다, SQL 문을 활용하여 해당 티켓의 관심 버튼을 누른 유저들이 가장 많이 관심 버튼을 누른 티켓을 추천하는 방식으로 의견을 일부 수용하였습니다.

#### 3. 마이페이지
- **관심 공연 알림 기능**: ‘관심 공연 알림’ 기능에 대한 선호도가 확연히 높아, 해당 기능의 구현에 집중하였습니다.
- **알림톡 대체**: 알림톡의 경우 사업자 등록이 필요하여, 메일로만 티켓 오픈 알림을 보내는 것으로 구현 범위를 확정하였습니다.
- **알림 시간 설정**: 티켓 오픈 N시간 전에 알림을 받고 싶다는 의견을 수용하여, 알림 목록 페이지에서 알림 시간을 설정할 수 있도록 구현하였습니다.

#### 4. 사이트 만족도
- **디자인 및 기능 만족도**: 사이트 디자인과 기능에 대한 만족도가 무난(혹은 중상)하다는 결과가 나왔습니다. UI에 대한 긍정적인 의견이 많았고, 부족하다는 평가가 없었기에 디자인은 유지하는 방향으로 확정하였습니다.
- **사용자 이탈 우려**: 사용을 고민해본다는 의견이 비중이 있는 편이고, 사용자의 이탈을 우려하는 의견도 있었습니다. 따라서 향후 커뮤니티나 댓글 기능을 추가하는 것도 고려하기로 하였습니다.

### 티켓정보 기능
| 기능                          | 상세 내용                                                                                                                                           |
|-------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| **세분화 된 티켓 정보 검색** | - 티켓의 **[공연 지역, 공연 날짜, 검색어]**를 필터로 검색 결과 제공<br>- 공연 지역 필터로 여러 개 또는 하나의 지역 선택 가능<br>- 달력을 통해 공연 날짜 당일 또는 기간 선택<br>- 장르, 제목 키워드를 통한 검색 가능 |
| **티켓 정보 상세 페이지**    | - 티켓 상세 정보(크롤링 데이터)<br>- 티켓의 제목, 출연진, 날짜, 지역 등 다양한 정보 제공                                                  |
| **지역 (지도 API)**          | - 지역 정보를 직관적으로 보여줄 수 있는 지도 API 사용<br>- 공연 위치를 지도로 통해 보여줌<br>- 지역 정보를 지도 API에 넘겨주면 위치를 자세하게 보여줌 |
| **관심 연령층**              | - 회원의 연령층을 통해 티켓 연령층 선호도 정보를 제공                                                                                          |
| **티켓 판매 플랫폼 이동**    | - 티켓 판매 플랫폼으로 직접 접속 가능                                                                                                           |

### 티켓 알람 시스템
| 기능            | 상세 내용                                                                                                                                                       |
|-----------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **관심 리스트** | - 상세 페이지에서 **좋아요 ON**<br>- 좋아요 ON 시 알람 버튼 추가<br>- 마이페이지의 관심 리스트에 티켓 정보 추가                                                |
| **알람**        | - 알람 리스트 제공<br>- 상세 페이지에서 알람 버튼 ON 또는 관심 리스트에서 알람 버튼 ON<br>- 각각의 티켓마다 알람 설정 가능<br>- 오픈 티켓 날짜에 따라 몇 시간 전 시간 설정 가능<br>- 백엔드에서 시간과 알람 메일 보내짐 여부에 따라 아이디(이메일)로 오픈 티켓 알람 이메일 발송![Image](https://github.com/user-attachments/assets/0668da57-8a8e-4ff1-9e72-04b9e1290577) |
